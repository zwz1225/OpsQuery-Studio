## 1. 依据与首轮决策

依据：[逐题归因报告](M3_A_FAILURE_ATTRIBUTION_20261021.md)、[机器证据](results/m3_a_failure_attribution_local_20261021.json)、[M2最终验收](M2_FINAL_ACCEPTANCE_20261019.md)。

M2 v4开发80题中50题原生通过、27题原生不匹配、3题未回答。主分类是排查分组，并非已由反事实执行证明的唯一根因；伴随原因与参考歧义单列。

**首轮选择SQL生成语义：公开输出需求的有序覆盖。** 实验标识：`m3_e01_public_output_contract`。

选择理由：

1. 0050、0085、0407的相关字段已经进入最终授权Schema，不需要同时改变检索才能检查输出问题。
2. 公开问题/evidence直接提供了输出顺序、计算项或字段组依据，适合建立有限语法的通用规则。
3. 现有修复已经能消除部分语法错误，但可执行SQL仍会漏列或换序；先把需求传给生成阶段，再测原生结果。
4. 9题主分类涉及检索/关系覆盖，影响范围更大，但混合了地点角色、表未锚定、未声明关联及公开歧义。首轮同时改这些变量难以解释收益和退化。

本轮并不认为输出问题比所有检索问题更重要；它是证据明确、范围较小、便于作对照的第一项。

## 2. 单一主动变量

从**原英文question、官方evidence及既有授权Schema**提取一个有来源的输出需求清单，加入生成提示：

```text
原公开请求
  → 有限语法识别主请求、补充输出请求和显式字段组定义
  → 绑定已提供的授权字段或公开计算表达式
  → 记录文本来源、位置、输出角色、请求顺序和歧义
  → 把有序清单加入生成提示
  → 现有校验、执行与有界修复
  → 输出契约检查仅作诊断
```

拟记录：`source=question/evidence`、原文span、公开请求角色、顺序、字段/公式绑定、解析是否完整、歧义、诊断结果及策略版本。

首版只改变生成提示中的结构化输出信息。新增检查器先报告，不新增强制拒绝、自动SQL重写、模型复核或重试。若以后提升为硬校验，另立实验。

暂定代码落点为独立的公开输出契约模块，以及现有`evaluation/bird/intent.py`、`case_worker.py`的最小接入；具体以实施时调用路径核对为准。`units_output.py`已有姓名/参与者字段组与单位策略，应复用；本轮不重写已有规则。

## 3. 适用与不适用边界

| 情况 | 本轮行为 |
| --- | --- |
| 先问地址，再要求学校名 | 按公开请求顺序保留两个输出角色 |
| 先问百分数，再补充地区代码 | 保留计算输出和代码，不让最后一句覆盖主请求 |
| evidence明确将一个输出术语定义为两个字段 | 在唯一绑定时保留字段组及定义顺序 |
| 只为排序使用的聚合量 | 不自动变成额外输出项 |
| full name、明确电话或成本 | 复用已有字段组规则和显式补充请求 |
| 用户名、语言、地点等仅作为筛选 | 不自动全部投影 |
| 明确only/除外/排除、不同请求之间冲突 | 显式限制优先；不完整或冲突时记录歧义 |
| CASE、聚合、CTE、多级表达式无法可靠归属 | 保留提示，不强制按字段数量或字符串相等拒绝 |
| 排名是排序还是额外名次列不明确 | 记录约定歧义，不依据Gold加列 |
| 布尔字符串大小写、布尔/文本类型未公开约定 | 不凭参考答案转换输出或改评分 |

不得使用case_id、Gold SQL、参考列名/列数、原生分数或人工逐题答案驱动运行规则。审查材料只用于选择实验和验证；case-list只含题号及公开用途说明。

## 7. 预先约定的筛选、接纳与停止条件

### 24题筛选

- 三个主目标至少2题原生通过，且相对同轮基线24题净增至少1题。
- 20个既有成功题在候选中全部保留，不能用主目标得分抵消成功题退化。

- 权限、来源泄漏、写操作、预算越界或截断结果评分任一发生即停止。
- 候选相对同轮基线的chat token总量和逐题p95若增加超过20%，暂不推广，先解释开销。该值是本轮工程筛选线，不是统计显著性标准。
- 若同轮基线已消除全部主目标问题，不用历史失分强称收益；记录波动后停止本候选推广。

### 完整80题接纳

- 固定80题分母，候选至少51/80且高于同轮基线；历史50/80继续单列，不覆盖。
- 原v4的50个成功题全部检查；有新增退化先逐题审查，不能无说明接纳，不能通过别名、改Gold或改EX抵消。
- 记录主目标、混合观察、20回归题、其他56题和全部8域的错转对/对转错；若只在混合题或参考歧义上偶合通过，不认定通用收益。
- 结果协议、隔离、安全和预算必须保持有效；输出契约引起的语义退化不接纳。
- 同样报告成本，原生EX提升不自动等于成本可接受或生产性能通过。

本轮是有限工程实验，一次模型对照不证明统计显著或广泛泛化。门槛未达到时保存失败候选、归档原因并回到下一优先问题，结束该实验，不持续追加验收重跑。
